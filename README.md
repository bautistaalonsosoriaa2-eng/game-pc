# Gamer PC (mod de Fabric 1.20.1)

## Obtener el .jar (la forma más fácil, sin instalar nada)
1. Crea una cuenta gratis en github.com y un repositorio nuevo.
2. Sube TODO el contenido de esta carpeta (incluida la carpeta oculta .github).
3. Ve a la pestaña **Actions** -> "Compilar mod" -> espera ~3 min.
4. Entra a la ejecución terminada y descarga **GamerPC-jar** (dentro está gamerpc-1.0.0.jar).
5. Ponlo en la carpeta `mods` junto con Fabric Loader y Fabric API (1.20.1).

(Alternativa: instala JDK 17 + Gradle 8.x y ejecuta COMPILAR.bat.)

## Cómo se juega
- Arma la torre: tarjeta madre -> RAM (32/100 GB) -> SSD (500 GB/1 TB).
- Pega la torre COMPLETA al lado del monitor: el monitor se enciende solo.
- Pon un teclado y un mouse a menos de 4 bloques del monitor.
- Pon un router a menos de 8 bloques del monitor y de la torre (no hace falta pegarlo).
- Clic derecho al monitor con la mano vacía: se abre la PC (Snake, Pong, Flappy y YouTube).
- YouTube solo funciona con router y se abre en tu navegador real (no dentro de Minecraft).
